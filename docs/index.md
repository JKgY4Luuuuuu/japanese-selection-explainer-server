# プライバシーポリシー

最終更新日：2026年9月1日

Japanese Selection Explainer（以下「本拡張機能」）は、Webページ上でユーザーが選択した文章を、AIを利用して解説・要約するChrome拡張機能です。

## 1. 取得・処理する情報

本拡張機能は、ユーザーがWebページ上で明示的に選択し、解説または要約を実行した文章を処理します。

本拡張機能は、ユーザーが選択していないWebページ上の文章を、解説・要約の目的で送信するものではありません。

## 2. 情報の利用目的

選択された文章は、以下の目的にのみ利用します。

- AIによる文章の解説
- AIによる文章の要約
- ユーザーが選択した解説モードに応じた回答の生成

## 3. 外部サービスへの送信

選択された文章は、解説・要約を生成するため、本拡張機能のバックエンドサーバーを経由してGoogle Gemini APIに送信されます。

本拡張機能では、バックエンドサーバーの運用にRenderを使用しています。

GoogleおよびRenderによるデータの取り扱いについては、それぞれのサービスのプライバシーポリシーおよび利用規約が適用される場合があります。

## 4. データの保存

本拡張機能の運営者は、ユーザーが選択した文章をデータベース等に恒久的に保存しません。

ただし、利用している外部サービスにおいて、サービス運用・セキュリティ・障害対応等の目的でログが処理または保持される場合があります。

#5. 個人情報の販売

本拡張機能は、ユーザーの個人情報または選択した文章を第三者に販売しません。

## 6. 利用目的外の使用

本拡張機能によって取得された情報を、広告、信用評価、ユーザー追跡など、本拡張機能の主要機能と無関係な目的には使用しません。

## 7. プライバシーポリシーの変更

本プライバシーポリシーは、本拡張機能の機能変更や利用サービスの変更等に応じて更新される場合があります。

重要な変更がある場合は、本ページを更新します。
